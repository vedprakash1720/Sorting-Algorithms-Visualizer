# Sorting-Algorithms-Visualizer
I have built a simple web-based Sorting Algorithms Visualizer built using HTML, CSS, and JavaScript.
It visually demonstrates how Bubble Sort, Selection Sort, and Insertion Sort work step by step.
Users can generate a random array, adjust size and speed, and watch the sorting process with color-coded bars showing comparisons, swaps, and sorted elements.

Link to the live Project  :  https://vedprakash1720.github.io/Sorting-Algorithms-Visualizer/
